❓ Frequently Asked Questions (FAQ)

Straightforward answers to key architectural, security, and licensing queries.

How does the module calculate vendor quality scores?
The module compares the total quantities demanded in Purchase Orders against the actual quantities received in warehouse pickings. It calculates delivery discrepancy ratios, return rates, and on-time compliance to maintain a live vendor performance rating.
Does it handle partial shipments and backorders?
Yes. When a vendor delivers in installments, the module tracks each incoming picking against the parent Purchase Order, ensuring accurate multi-delivery accounting without skewing discrepancy rates.
Can I configure custom tolerance thresholds per supplier?
Absolutely. You can define custom quality rules with specific percentage tolerances (e.g. allowing +/- 2% on bulk commodities while enforcing 0% on serialized or high-value items).
Is this module compatible with Odoo.sh?
Yes, 100%. The module strictly follows standard Odoo ORM development guidelines with zero external system binaries or C-library dependencies.
