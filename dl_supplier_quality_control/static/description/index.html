Módulo Odoo 17

DL Supplier Quality Control

Avaliação Automática do Desempenho dos seus Fornecedores (Vendor Rating)

Tenha controlo total sobre as falhas de entrega! Este módulo monitoriza todas as entradas no armazém, compara o que foi pedido com o que foi entregue, e alerta automaticamente a sua equipa quando um fornecedor não cumpre os padrões de qualidade acordados.

Funcionalidades Principais

Cálculo de Diferenças

Veja instantaneamente na tela e no PDF se o fornecedor entregou mercadoria a menos do que a Ordem de Compra exigia.

Regras Automáticas

Configure regras (ex: "Taxa de cumprimento inferior a 90%") e deixe que o Odoo notifique os gestores através das Atividades quando a regra for quebrada.

Dashboards Avançados

Relatório dinâmico em Pivot com o histórico total das entregas. Identifique imediatamente os piores e os melhores parceiros de negócio.

Ficha de Fornecedor Inteligente

Na ficha de cada fornecedor (Contacto), o sistema adiciona uma métrica inteligente de Taxa de Cumprimento Global. Se o fornecedor violar as Regras de Qualidade parametrizadas, o Odoo exibe um alerta visual destacado a vermelho de Falhas Recorrentes, fornecendo dados valiosos para o departamento de Compras mitigar riscos e tomar melhores decisões de aprovisionamento.
